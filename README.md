# Data Career Map

Анализ рынка вакансий Data Science, Machine Learning, AI и аналитики
методами статистики и машинного обучения.

## Цель проекта

Исследовать различия между современными профессиями в области Data Science
и искусственного интеллекта по требуемым навыкам, опыту и другим
характеристикам вакансий.

Дополнительная цель — проверить, можно ли определить профессиональное
направление вакансии на основании набора требуемых технологий.

## Исследуемые направления

- Data Analyst
- BI Analyst
- Data Scientist
- ML Engineer
- Data Engineer
- MLOps Engineer
- AI / LLM Engineer
- Python Developer

## Pipeline

Data Collection → Data Cleaning → EDA → Statistical Analysis →
Feature Engineering → Machine Learning → Interpretation

## Technologies

- Python
- pandas
- NumPy
- requests
- BeautifulSoup
- Matplotlib
- SciPy
- scikit-learn

## Project structure

- `data/raw` — исходные данные
- `data/processed` — обработанные данные
- `notebooks` — анализ данных
- `src` — Python-модули
- `images` — графики и результаты
